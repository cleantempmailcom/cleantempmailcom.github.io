A LITTLE MORE CLARITY

Temporary email: frequently asked questions.

For more guidance, visit the
Help center ↗

What is a temporary or disposable email address?+

A temporary email address gives short-term messages a separate inbox. It can be useful for permitted one-off downloads, product trials and testing your own app. Start with the temporary email usage guide to learn how to receive and manage messages.

Why am I not receiving a verification code or email?+

Check that the full address matches the inbox you are viewing and that the sender actually sent the message. Refresh the inbox, follow the sender’s retry guidance and check for address restrictions. The missing email troubleshooting guide walks through each stage.

Are the web inbox and API both free?+

The web inbox is free. Independent API keys are paid, with a fixed request quota. A limited shared test key is available for evaluation.

Is the API a subscription? Can I top up a key?+

No subscription or auto-renewal. Each purchase issues an independent key. Existing keys cannot be topped up; purchase a new key for more requests.

Do empty inbox checks consume API quota?+

Yes. Protected requests count after authentication, including empty results, repeated polling, and some handler errors. Public domain listing and quota checks do not count. See API polling and request budgets for a worked example.

Can I use my own domain?+

Yes. Follow the main website’s MX setup instructions and submit your domain for verification. The custom domain email guide explains how to plan the setup and check delivery.

Do I need an account to use CleanTempMail?+

No sign-up is required. Visit CleanTempMail to create a free temporary address and read incoming emails in your browser.

Can I choose the email domain?+

Yes. CleanTempMail offers multiple domains. Check the main website for the current selection and availability.

Is temporary email suitable for long-term use?+

Temporary email is best suited to short-term trials and testing. Use a personal email address you control long-term for ongoing accounts, important information, and password recovery. Compare temporary email, permanent email and aliases by use case.

Why do some websites reject temporary email?+

Each website has its own email validation rules, and some services restrict temporary addresses. Please follow the rules of the service you use.

Can I receive emails on this page?+

This is a product introduction page. Select “Create a free inbox” to visit CleanTempMail and use the actual email service.

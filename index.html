A LITTLE MORE CLARITY

临时邮箱常见问题。

临时邮箱是什么，适合哪些场景？+

临时邮箱也常被称为一次性邮箱，用独立地址接收短期需要的邮件，适合对方允许的一次性资料获取、产品体验和自己的应用测试。可以先阅读临时邮箱使用指南，了解创建地址、查看邮件和管理收件箱的步骤。

临时邮箱收不到验证码或邮件怎么办？+

先核对完整地址与当前收件箱是否一致，再确认发送方已经触发邮件；刷新收件箱，并按发送方提示等待或重试。若提示不接受临时地址，应使用对方允许的邮箱。查看收不到邮件的逐步排查指南，定位问题发生在哪个环节。

网页邮箱和 API 都免费吗？+

网页临时邮箱免费、无需注册。API 面向自动化调用，独立密钥按请求额度一次性购买；共享测试密钥仅供体验。

API 是订阅制吗？可以充值吗？+

不是订阅，没有自动续订。每次购买生成一个独立密钥，额度不能追加到原密钥；需要更多额度时购买新密钥。

轮询空收件箱也会扣 API 额度吗？+

会。受保护 API 在密钥通过认证后即计次，空结果、重复轮询及部分处理错误仍会消耗额度。公开域名列表和剩余额度查询不扣额度。可参考API 轮询与请求额度计算示例。

能使用自己的域名吗？+

可以。按官网说明配置 MX 记录，并在自有域名入口提交验证。自有域名临时邮箱配置指南介绍了配置规划与投递检查；域名接入与可用情况以官网为准。

使用 CleanTempMail 需要注册吗？+

无需注册。直接访问官网即可创建免费临时邮箱，并在网页上查看收到的邮件。

可以选择邮箱域名吗？+

可以。官网提供多种可用域名供选择；具体域名及可用情况以官网实时显示为准。

临时邮箱适合长期使用吗？+

建议用于短期体验与测试。对于长期账户、重要资料和密码找回，使用你长期掌控的个人邮箱更合适。查看临时邮箱、长期邮箱与别名的场景比较，按后续访问需求选择。

为什么有的网站不接受临时邮箱？+

不同网站有自己的邮箱验证规则，部分服务会限制临时邮箱。请遵守对方的使用规则。

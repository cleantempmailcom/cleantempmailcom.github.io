# CleanTempMail

CleanTempMail 推广站，直接部署在 GitHub Pages 根地址。

- 中文：https://cleantempmailcom.github.io/
- English：https://cleantempmailcom.github.io/en/

站点文件位于仓库根目录（由 `main` 分支直接发布）。修改后可在本地运行校验：

```
python3 scripts/check_seo.py
node scripts/check_language.cjs
```

本仓库已合并原 `cleantempmail-pages` 仓库的内容。

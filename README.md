# CleanTempMail GitHub Pages 根地址

将 https://cleantempmailcom.github.io/ 自动跳转到现有宣传站 https://cleantempmailcom.github.io/cleantempmail-pages/。

JavaScript 跳转保留查询参数与片段链接；禁用 JavaScript 时由 HTML meta refresh 跳转，并提供手动链接。

Pages 发布源：main 分支的根目录。宣传站继续在 cleantempmail-pages 仓库维护。

根目录的 `robots.txt` 声明推广站的站点地图，供搜索引擎发现指南页面。它不会自动完成 Search Console 所有权验证或保证收录。
